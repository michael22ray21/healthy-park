# Healthy Park 🎮🌱

Healthy Park is a simple interactive game prototype designed for pop-up events or activations promoting healthy eating. The idea is to create a fun and engaging way for people—especially passersby—to learn about healthy food choices through play.

The project was built as part of a concept where a company that promotes healthy eating could set up a pop-up booth with digital and interactive elements to capture attention, spark curiosity, and encourage positive habits.

## ✨ Features
- 🎨 Engaging Gameplay – Designed to be approachable and easy for anyone to try.
- 🥦 Health-Focused Theme – Core gameplay revolves around healthy eating and nutrition.
- 🚶 Pop-Up Friendly – Simple setup intended for short, interactive experiences.
- 💡 Awareness Through Play – Encourages participants to think about food choices in a fun way.

## 🏗️ Project Background
The project was developed as an experimental prototype, imagining how a health-focused company could create a more memorable experience at public events. Instead of static banners or brochures, the booth offers something interactive—helping the brand connect better with audiences.
