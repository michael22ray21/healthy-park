# Healthy Park 🎮🌱
Healthy Park is a motion-interactive game created as part of a pilot project for a pop-up business idea. The concept was to design an engaging booth experience where people could interact with healthy eating themes in a playful, memorable way.

Instead of traditional flyers or static displays, the project envisions a motion-controlled interactive setup that attracts passersby, sparks curiosity, and communicates the importance of healthy living through fun digital play.

## ✨ Features
- 🎮 Interactive Gameplay – Built to explore the use of body movement as a controller. It uses camera tracking to translate movement into moving the character.
- 🥦 Health-Themed Experience – Core design promotes healthy eating and lifestyle awareness. Players are directed to catch healthy food that drops and to be careful not to catch the unhealthy ones. Each healthy food caught will add points based on the food itself, and each healthy food missed of each unhealthy food caught will deduct points.
- 🚶 Pop-Up Ready – Conceptualized for short, interactive booth engagements. Each game features 3 lives and progressive difficulty as drops become more frequent and faster as game goes on.
- 💡 Pilot Project – Serves as a proof-of-concept for a future motion-based event product.
